## 💡 NOTES TECHNIQUES

### Logo dans l'application
```html
<img src="logo.png" alt="EcomLik">
```
- Le logo est chargé depuis le fichier `logo.png`
- Si le fichier n'existe pas, il sera caché automatiquement
- Format PNG avec transparence

### Favicon
```html
<link rel="icon" type="image/png" href="...">
```
- Version miniature du logo
- Visible dans l'onglet du navigateur
- Format base64 pour rapidité

### Couleurs CSS
```css
/* Rouge EcomLik */
background: linear-gradient(135deg, #D32F2F 0%, #F44336 100%);

/* Jaune/Or EcomLik */
background: linear-gradient(135deg, #FDB913 0%, #FFCD3C 100%);
```
